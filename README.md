# 게임잡 채용공고 트래커

게임잡(gamejob.co.kr) 전체 채용공고를 매달 수집해서
신규/삭제(마감) 공고 수, 직무별 공고 수, 기업별 공고 수(최다/최소)를
자동으로 리포트로 만들어주는 스크립트입니다.

## ⚠️ 먼저 읽어주세요

이 스크립트는 제가 이 사이트에 **직접 접속해서 실시간으로 테스트하지 못한 상태**로
작성했습니다 (제 실행 환경에서는 이 사이트 접속이 막혀있어요). 그래서 HTML 구조가
예상과 다르면 파싱이 안 될 수 있습니다. **반드시 아래 순서대로** 진행해주세요.

## 1단계: 설치

```bash
pip install -r requirements.txt
```

## 2단계: 구조 확인 (필수, 최초 1회)

```bash
python gamejob_tracker.py --debug
```

실행하면 `data/debug/` 폴더에 원본 HTML 파일들이 저장되고,
터미널에 아래처럼 "공고링크 발견: True/False" 가 출력됩니다.

```
- 후보 0 (.../recruit/_GI_Job_List?Page={page}) -> 저장됨: ... (공고링크 발견: True)
- 후보 1 (...) -> 저장됨: ... (공고링크 발견: False)
```

- **True가 하나라도 있으면** 3단계로 넘어가면 됩니다.
- **전부 False면** `data/debug/` 안의 html 파일 중 하나를 저에게 보여주세요
  (전체 다 필요 없고, 채용공고 목록이 있는 부분만 일부 복사해서 붙여넣어 주시면
  파싱 코드를 구조에 맞게 고쳐드릴게요).

## 3단계: 실제 실행

```bash
python gamejob_tracker.py --run
```

- 전체 공고를 페이지별로 순회하며 수집합니다.
- 그 다음 **공고 하나하나의 상세페이지에서 정확한 직종("모집분야")을 가져옵니다**
  (게임잡 필터에 나오는 "게임개발(클라이언트) 200건" 같은 정식 분류 그대로예요).
  처음 실행할 때는 전체 공고 수만큼 상세페이지를 조회하느라 시간이 좀 걸려요
  (1,500건 기준 5~10분 정도). **두 번째 실행부터는 이미 조회한 공고는 건너뛰고
  새로 생긴 공고만 조회**하기 때문에 훨씬 빨라집니다.
  (이 정확한 직종 조회를 생략하고 빠르게만 돌리고 싶으면 `--skip-categories`
  옵션을 붙이면 제목 키워드 추측 방식으로만 분류합니다.)
- 끝나면 아래 파일들이 생성됩니다.

```
data/
  job_categories_cache.csv          # 공고별 정확한 직종 캐시 (지우지 마세요! 지우면 처음부터 다시 조회함)
  snapshots/2026-09-01.csv          # 이번 실행 시점 전체 공고 스냅샷
  reports/2026-09-01_report.md      # 사람이 읽기 좋은 요약 리포트
  reports/2026-09-01_new_jobs.csv   # 신규 등록 공고 (이전 스냅샷 있을 때만)
  reports/2026-09-01_removed_jobs.csv # 삭제/마감된 공고 (이전 스냅샷 있을 때만)
  reports/2026-09-01_company_stats.csv     # 기업별 공고 수 전체
  reports/2026-09-01_job_function_stats.csv # 직종별 공고 수 전체 (정확한 분류 기준)
```

- **처음 실행할 때는 "이전 스냅샷"이 없어서** 신규/삭제 비교는 안 나오고
  현재 시점 전체 현황(직종별/기업별 집계)만 나옵니다.
- **두 번째 실행부터** (한 달 뒤) 이전 달과 비교한 신규/삭제 공고 리포트가 나옵니다.

## 4단계: 매달 자동 실행 (선택)

### Mac/Linux (cron)

```bash
crontab -e
```

아래 줄 추가 (매달 1일 오전 9시 실행):

```
0 9 1 * * cd /스크립트가있는/경로 && /usr/bin/python3 gamejob_tracker.py --run >> run.log 2>&1
```

### Windows (작업 스케줄러)

1. "작업 스케줄러" 실행 → "기본 작업 만들기"
2. 트리거: 매월 1일
3. 동작: 프로그램 시작
   - 프로그램: `python`
   - 인수: `gamejob_tracker.py --run`
   - 시작 위치: 스크립트가 있는 폴더 경로

## 참고사항

- **직종 분류는 이제 게임잡의 정식 분류를 그대로 사용합니다.** 공고 상세페이지의
  "모집분야" 항목을 그대로 가져오기 때문에, 게임잡 필터 화면에서 보이는 숫자와
  거의 동일하게 맞아떨어져요. 상세페이지 조회에 실패한 극소수 공고만 예외적으로
  제목 키워드 추측(`JOB_FUNCTION_KEYWORDS`)으로 대체됩니다.
- 공고 하나가 여러 직종에 걸쳐있을 수 있어요 (예: "게임개발(클라이언트), 게임개발(모바일)").
  이런 경우 리포트의 직종별 집계에서는 각 직종에 한 번씩 카운트되기 때문에,
  직종별 합계가 전체 공고 수보다 많을 수 있습니다 (게임잡 사이트도 마찬가지 방식이에요).
- 마감된 공고가 실제로 "삭제"된 건지, 그냥 채용 기간이 남아있지만 리스트 순서가
  바뀐 건지는 gi_no(공고번호) 기준으로 판단합니다. 이전 스냅샷에 있었는데
  이번 스냅샷에 없으면 "삭제/마감"으로 집계됩니다.
- 사이트에 과부하를 주지 않도록 페이지 요청 사이 0.5초 딜레이가 걸려 있습니다
  (`crawl_all_listings`의 `sleep_sec` 값으로 조절 가능).
